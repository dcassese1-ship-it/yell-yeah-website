# Product images

Drop product photos here using these exact filenames (referenced from `src/lib/products.ts`):

- `shirt-1.jpg`
- `shirt-2.jpg`
- `shirt-3.jpg`
- `shirt-4.jpg`
- `hat-1.jpg`
- `hat-2.jpg`

Square images work best (the product grid crops to a 1:1 tile). `.png` or `.webp` also work —
just update the matching `image` path in `src/lib/products.ts` to match the extension you use.
